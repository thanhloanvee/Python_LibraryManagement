# Phase 1 - Analyze Project & Understand System

## Goal

Analyze the entire codebase and understand the project from both business and technical perspectives.

This is NOT a code review task.

This is NOT a software architecture audit.

The objective is to understand:

* What problem the system solves
* Who uses the system
* How the system works
* What technologies are used
* What modules exist
* What business processes are supported

## Instructions

Read the entire repository.

Generate a structured document:

### 1. Project Overview

* Project name
* Project purpose
* Target users
* Main objectives

### 2. Business Context

* Problem statement
* Why the system exists
* Expected benefits

### 3. System Overview

* High level architecture
* Main modules
* Module responsibilities

### 4. Technology Stack

Identify:

* Programming languages
* Frameworks
* Libraries
* Database
* UI technologies
* Development tools

Explain the purpose of each technology.

### 5. Project Structure

Explain:

* Folder structure
* Main packages
* Main classes
* Main components

### 6. Business Logic

Identify:

* Main workflows
* Core business processes
* Key interactions between users and system

### 7. Roles & Permissions

Identify:

* User roles
* Permissions
* Restrictions

### 8. Main Features

List all major system features.

### 9. Database Analysis

Identify:

* Entities
* Relationships
* Database structure

### 10. Presentation-Relevant Information

Identify content suitable for presentation:

* Business flow
* System architecture
* Technologies
* Features
* User interactions

Save result to:

/docs/PROJECT_ANALYSIS.md

# Phase 2 - Generate Presentation Design Context

This document will be used as the primary context source for PowerPoint AI tools such as Gamma, Canva AI, Beautiful.ai, and PowerPoint Copilot.

Focus on:

* Business understanding
* Technology introduction
* System overview

* Deep implementation details
* Code-level explanations
* Algorithm discussions

### 2. System Objectives

### 3. Target Users

### 4. Technology Stack

### 5. System Architecture Overview

### 6. Database Design Summary

### 7. ERD Description

### 8. Business Logic Flow

### 9. Roles & Permissions Summary
